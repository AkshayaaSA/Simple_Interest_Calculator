# Simple Interest Calculator

## Description
This project is a simple interest calculator that computes the simple interest
based on the principal amount, rate of interest, and time period provided by the user.

## Formula Used
Simple Interest (SI) = (Principal × Rate × Time) / 100

## Inputs
- Principal amount (P)
- Rate of interest (R)
- Time period in years (T)

## Output
- Calculated Simple Interest value

## Algorithm
1. Read the principal amount from the user.
2. Read the rate of interest.
3. Read the time period.
4. Apply the simple interest formula.
5. Display the calculated simple interest.

## How to Run
1. Clone the repository.
2. Open the project folder.
3. Run the program using the appropriate command for the language used.

## Example
Input:
- Principal = 1000
- Rate = 5
- Time = 2

Output:
- Simple Interest = 100
